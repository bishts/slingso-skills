# Extraction cases

The answers and expected facts Slingso grades every extractor on: the server's own
(Growth) and this skill running in the brand's Claude (Free, Starter). One set of
cases, one grader, so the two can't drift apart.

`extraction-brand-ranked` and `extraction-brand-absent` use these answers verbatim.
Change a case here and in its eval folder together; Slingso's copy changes with it.
